# UT1-A2 Sintaxis Markdown
## Introducción

**README.md** es un documento en formato **Markdown**, hecho para hacer la tarea UT1-A2 y trabajar con Markdown.

## Que hacer

1. Crear un archivo README.md.
2. Abrir el archivo y escribir el texto en Markdown. Se necesita:
	- Por lo menos 1 palabra en **negrita**;
	- Por lo menos 1 palabra en *cursivo*;
	- Un enlace externo y una imagen utilizando "sintaxis Markdown";
	- Un fragmento de codigo con sintaxis adecuada;
	- Una cita en bloque final.
3. Guardar el documento y hacer un commit y push:
	~~~
	cd (tu carpeta del repositorio local)
	git add README.md
	git commit -m "Mensaje del commit"
	git push
	~~~
